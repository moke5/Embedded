# 模板说明

> 本目录是所有笔记模板的统一入口。新建笔记时复制对应模板，填入 frontmatter 和正文。
> 模板设计依据认知科学的学习理论，每一条字段都对应一个经过验证的学习机制，不凭感觉设。

## 一、科学依据：认知科学原理 → 模板机制

| 认知科学原理 | 含义 | 模板中的落地 |
| --- | --- | --- |
| 学习的本质 | 学习是长期记忆中心理表征的改变，不是"看过" | 每篇笔记必须有「用自己的话重写」，禁止只摘录 |
| 心理表征 | 知识在脑中的结构化组织，专家靠组块 | 强制画概念图/Mermaid，把零散信息组织成结构 |
| 概念是学习的基石 | 概念是思维的最小单元，无概念则无推理 | [概念卡片](./概念卡片.md)：定义→边界→反例→上位下位 |
| 流体智力 vs 晶体智力 | 流体=推理能力，晶体=知识积累；两者训练方式不同 | frontmatter 的 `target` 字段，明确这次在练哪一种 |
| 思维模型 | 可跨领域迁移的思考框架 | 笔记结尾写「这个模型还能迁移到哪些场景」 |
| 刻意练习 | 目标明确+即时反馈+走出舒适区+重复弱点 | [刻意练习](./刻意练习.md)：目标/弱点/反馈/复盘 |
| 明确输入输出 | 学完必须有具体产出，否则等于没学 | frontmatter 的 `input`/`output` 字段 |
| 对比反馈学习法 | 对比产生辨别力，反馈校正错误表征 | [对比辨析](./对比辨析.md) + [自测题](./自测题.md)（答案即反馈） |
| 行动力大中小原则 | 任务拆成大/中/小三档，用小事启动降低启动阻力 | 待办列表按 大/中/小 分级 |
| 主动回忆 | 提取练习远胜重复阅读（Roediger & Karpicke） | [自测题](./自测题.md)，Q&A 与填空 |
| 间隔重复 | 艾宾浩斯遗忘曲线：1-3-7-14-30 天复习 | [复习计划](./复习计划.md) + frontmatter 的 `review` 字段 |
| 费曼技巧 | 讲给外行听懂，暴露理解缺口 | 概念卡片首行「费曼版一句话」 |

## 二、frontmatter 规范（全仓库统一）

**必填字段**（人和 AI 都按这套读写）：

```yaml
---
type: 概念        # 笔记类型：概念/课程/实验/踩坑/读书/项目/对比/自测/练习/复习/MOC/工具
tags: [stm32]     # 领域标签，小写英文或中文
status: 进行中    # 进行中 / 已完成 / 待整理
created: 2026-01-01   # 创建日期，YYYY-MM-DD
updated: 2026-01-01   # 最后修改日期
related: [[串口通信]]  # 相关笔记的双向链接
---
```

**科学学习法推荐字段**（不强制，但强烈建议填）：

```yaml
target: 晶体          # 流体（练推理）/ 晶体（积累知识）
input: 课程第 3 讲     # 本次学习的输入来源
output: 时序图 + 测试代码  # 本次学习的产出成果
review: 2026-10-20    # 下次复习日期（间隔重复）
```

## 三、检索方式

- **命令行 / AI**：`grep -rn "^type: 踩坑" --include="*.md" .`、`grep -rln "stm32" --include="*.md" .`
- **Obsidian**：属性面板筛选，或 Bases 按 type/tag/status 建视图
- **人工浏览**：各主题目录下的 `MOC.md` 静态索引（索引是权威入口，动态视图只是增强）

## 四、使用方式

- **Obsidian**：设置 → 核心插件 → 启用「模板」，模板文件夹位置设为 `模板`；`{{date}}` 会被自动替换为当天日期。想要动态日期可装 Templater 插件
- **Typora / 命令行**：直接复制模板文件，手动改日期
- **AI**：AI 新建笔记前必须先读本文件与根目录 `AGENTS.md`，按规范填 frontmatter

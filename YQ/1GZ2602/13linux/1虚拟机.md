## **1. WSL简介**

Windows Subsystem for Linux（简称WSL）是Windows系统自带的轻量级虚拟机，是微软推出的Windows系统兼容层，核心功能是让Windows 10/11用户无需安装虚拟机或进行双系统设置，就能原生运行Linux二进制可执行文件（ELF格式），直接使用Linux命令行工具、脚本及应用程序，实现Windows与Linux环境的无缝集成。

### **1.1 WSL的核心特性**

1. 原生Linux环境支持：可运行Ubuntu、Debian、Kali、CentOS等主流Linux发行版的二进制文件，支持Bash、Zsh等Shell，以及grep、sed、awk、Python、GCC等常用命令行工具和编程语言，无需修改代码即可在Windows上使用Linux生态。
2. Windows与Linux深度集成：可以通过/mnt目录可直接访问Windows磁盘，方便跨系统编辑文件（如用VS Code在Windows中修改Linux中的代码），应用程序互调：可在Linux中运行Windows程序（如notepad.exe、calc.exe），也可在Windows中运行Linux工具（如bash.exe）。
3. 轻量高效：相比传统虚拟机（如VMware、VirtualBox），WSL占用资源更少（启动速度快、内存占用低），且不会影响Windows主机的性能。

### **1.2 WSL的两个主要版本**

WSL分为WSL 1和WSL 2两种架构，主要差异在于内核实现和性能表现：

| 特性     | WSL1                                                         | WSL 2                                              |
| -------- | ------------------------------------------------------------ | -------------------------------------------------- |
| 架构设计 | 通过系统调用转换层（将Linux syscall转为Windows NT syscall）实现兼容 | 基于Hyper-V的轻量级虚拟机，运行完整的Linux内核     |
| 性能表现 | 文件IO较慢（跨系统访问时延迟高）                             | 文件IO接近原生Linux速度（尤其是Linux内部文件操作） |
| 兼容性   | 部分Linux系统调用不支持（如某些内核特性）                    | 完整支持Linux内核的所有系统调用                    |
| 内存占用 | 较低（无内置虚拟机）                                         | 较高（有内置虚拟机，但动态分配内存）               |

## **2. WSL与Ubuntu**

### **2.1 WSL测试与激活**

一般而言，win10/11系统都默认安装有 WSL 虚拟机组件的，可以用下面的方式测试一下：

**一、** 点击开始菜单，输入 `powershell` ，以管理员身份打开：

![image-20260524164936770](./1虚拟机.assets/image-20260524164936770.png)

**二、** 在终端中输入 `wsl -v` 可以查看当前系统的 WSL 信息：

![image-20260524164950844](./1虚拟机.assets/image-20260524164950844.png)

![image-20260524165015602](./1虚拟机.assets/image-20260524165015602.png)

如果显示如上图所示，就表示系统已经有 WSL 了。若显示找不到 `WSL` 命令，那可能是当前操作系统不支持 WSL。可以参照下一节教案安装虚拟机 `VMware`。

### **2.2 Ubuntu下载安装**

在 `WSL` 中安装 Ubuntu 有多种方式。

**a. 商店安装**
打开商店，搜索最新的LTS版的Ubuntu，比如Ubuntu-24.04LTS：

![image-20260524165041089](./1虚拟机.assets/image-20260524165041089.png)

正常情况下会进入设置系统的界面：

![image-20260524165056317](./1虚拟机.assets/image-20260524165056317.png)

根据界面提示，依次输入用户名和密码即可：

![image-20260524165110742](./1虚拟机.assets/image-20260524165110742.png)

**b. 命令行安装**
以管理员权限打开 `powershell` 或命令终端，检测当前 `WSL` 中已有的 Linux 发行版（分发系统）：

```powershell
wsl --list --verbose
```

![image-20260524165136381](./1虚拟机.assets/image-20260524165136381.png)

若未能检测到任何Linux发行版系统，输入以下命令检测当前网络可供下载的列表：

```powershell
wsl --list --online
```



若检测到可用的 Linux 发行版：

![image-20260524165200914](./1虚拟机.assets/image-20260524165200914.png)



输入以下命令下载并安装 Ubuntu：

```powershell
wsl --install -d Ubuntu-24.04
```

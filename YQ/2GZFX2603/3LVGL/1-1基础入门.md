## 工程配置解析

LVGL可以在各种平台和环境运行，为便于描述，后续除非特意标注，否则约定如下：

- 案例运行平台默认为 Windows 平台
- LVGL默认为 V9.2 版本源码

### **1. 源码结构**

要使用 LVGL，首先得对其源码结构有较清晰的认识，下面是 LVGL 9.2 源码的结构：

| /lvgl                   | demos/         | 官方提供的综合案例代码                                       |
| /lvgl                   | env_support/   | lvgl对各种平台的支持配置文件，包括ESP平台、实时系统RTT、zephyr等 |
| /lvgl/env_support/cmake | custom.cmake   | 默认的真正的cmake配置信息 在该文件中，可以控制lvgl各种库的编译形态（动态、静态） |
| /lvgl/examples/         | anim/          | 动画相关官方示例代码                                         |
| /lvgl/examples/         | event/         | 事件相关官方示例代码                                         |
| /lvgl/examples/         | layouts/       | 布局相关官方示例代码                                         |

## 基础对象obj

### **1. LVGL的对象**

LVGL虽然是用C语言编写的，但工程设计思路采用面向对象的编程思想(OOP)，因此我们可以采用面向对象的一些诸如基类、子类、继承、派生这些术语来形象地描述 LVGL 中的各种对象。

![img](./img/rBJlJmfdG7OAeyCNAAE7EZEmDK8772.jpg)

整个 LVGL 最基础的对象(基类）是 `lv_obj_t`，其他所有的控件(Widgets)都是 `lv_obj_t` 的子类，例如，按钮，标签，图像，列表，图表或文本区域，这些看起来纷繁各异的控件，由于都是从同一个基类派生而来的，因此他们有一些大家都具备的，相似的属性和行为，因此，在各个击破这些控件之前，非常有必要先熟悉 `lv_obj_t` 的特性。

#### **1.1 父子对象**

lv_obj_t (类)定义了控件的抽象特点，其定义包含了数据的形式以及对数据的操作。控件(子类)比原本的类(称为父类或基类)要更加具体化，子类会继承父类的属性和行为。定义一个对象时，可以给这个对象指定它的父对象：

```
// 提示：每个对象创建的时候都有父对象
lv_obj_t *lv_obj_create(lv_obj_t *parent); 
```







**父子对象在视觉上的关系**
默认情况下，父子对象视觉上的关系有：

- 子对象在父对象内显示
- 子对象会随着父对象的移动而移动（包括缩放和旋转）
- 子对象会随着父对象的隐藏而隐藏

例子1，在屏幕（父对象）上创建一个标签，令其左半部分移出屏幕，可以看到超出父对象的部分默认是不可见的：

**父子对象在内存上的关系**
LVGL 中这种父子对象关联关系还有一个很重要的作用，就是利用父对象来统一管理所有的子对象内存资源，想象一下，在一个多屏幕或多页面APP中，一个屏幕或页面下可能有很多控件，当关闭这一屏幕或页面时，如果不能自动回收其下的所有子对象资源，那将是多么难受的一件事。

下面展示了一个直观示例，假设在屏幕上创建一个蓝色基础对象作为父对象，然后再在该父对象下创建两个子对象，比如一个圆形、一个正方形。此时如果点击按钮删除父对象，那么其子对象也会被一并删除。

![img](./img/rBJlJmjsm_iAVGJdAAA60zweGWk819.gif)

核心代码在 `lvgl/src/core/lv_obj_tree.c` 中：

```
static void obj_delete_core(lv_obj_t * obj)
{
    ... ...
    ... ...

    /*Recursively delete the children*/
    lv_obj_t * child = lv_obj_get_child(obj, 0);
    while(child) {
        obj_delete_core(child);
        child = lv_obj_get_child(obj, 0);
    }

    ... ...
    ... ...
}
```







#### **1.2 常用接口**

下面是 `lv_obj_t` 基础对象的常用接口，包括设置、获取对象的大小、位置、对齐方式等。

```
// 设置宽度、高度
lv_obj_set_width(obj, new_width);
lv_obj_set_height(obj, new_height);
lv_obj_set_size(struct _lv_obj_t *obj, lv_coord_t w, lv_coord_t h)

// 获取宽度、高度
lv_obj_get_width(obj);
lv_obj_get_height(obj);

// 设置x轴、y轴方向的坐标位置
lv_obj_set_x(obj, new_x);
lv_obj_set_y(obj, new_y);
lv_obj_set_pos(struct _lv_obj_t *obj, lv_coord_t x, lv_coord_t y);

// 获取x轴、y轴方向的坐标位置
lv_obj_get_x(obj);
lv_obj_get_y(obj);

// 设置对齐
lv_obj_align(obj, LV_ALIGN_OUT_TOP_MID, 0, 0);
lv_obj_align_to(obj, baseobj, LV_ALIGN_OUT_TOP_MID, 0, 0);

// 设置圆角
lv_obj_set_style_radius(obj, radius, selector);
```







#### **1.3 盒子模型**

LVGL 遵循 CSS 的 border-box 模型。 对象的“盒子”由以下部分构成：

- 边界(bounding)：元素的宽度/高度围起来的区域(整个盒子)。
- 边框(border)：边框有大小和颜色等属性(相当于盒子的厚度和它的颜色)。
- 填充(padding)：对象两侧与其子对象之间的空间(盒子的填充物)。
- 内容(content)：如果边界框按边框宽度和填充的大小缩小，则显示其大小的内容区域(盒子实际装东西的区域)。
- 轮廓(outline) ：LVGL中没有外边距(margin)的概念(盒子之间的距离)，确认代之的是轮廓(outline)。它是绘制于元素(盒子)周围的一条线，它不占据空间，位于边框边缘的外围，可起到突出元素(盒子)的作用。在浏览器里，当鼠标点击或使用Tab键让一个选项或者一个图片获得焦点的时候，这个元素就会多了一个轮廓框围绕。

![img](./img/rBJlJmfdHduAAkvoAAAtpfAaFg0861.jpg)

LVGL的盒子模型是我们理解对象(部件)的组成，修改对象的样式，实现对对象的布局、处理对象排列等等的关键。

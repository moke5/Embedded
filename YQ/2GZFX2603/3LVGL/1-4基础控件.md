## **2. 图像（Images）**

LVGL 不直接支持 PNG 或 JPG 等这些通用的图像格式，但可以有两种方式显示图像：

1. 针对有限图像场景，使用图片生成器，只生成所需要的图像其余不要，节省内存空间
2. 针对不限图像场景，使用第三方库，如JPG、PNG等
    下面针对这两种不同的需求，列出操作步骤：

### **2.1 针对有限图像场景**

通过[图像生成器](https://lvgl.io/tools/imageconverter)，转化为LVGL所支持的图像格式：
如下图所示，将几张jpg和png的图片，转化成RGB数据，并写入C语言数组中，形成对应的 *.c文件（比如 `balloon.jpg`会被生成`balloon.c`）：

![img](./img/rBJlJmfg_82AB6MQAAC_MiClXr0299.jpg)

接着，将图片生成的 *.c 文件（比如 `balloon.c`）放入工程目录中，并修改 `CMakeLists.txt`：
![img](./img/rBJlJmfhAGyAQlqTAAEpbIDk_Vg134.jpg)



然后，在代码中显示气球图片：

```
// 声明图片数据所在的数组名称
LV_IMG_DECLARE(balloon);
// 创建对象
lv_obj_t * img1 = lv_img_create(lv_scr_act());
// 加载指定图片
lv_img_set_src(img1, &balloon);
lv_obj_align(img1, LV_ALIGN_CENTER, 0, -20);
// 将obj的宽设置为当前screen的100%的宽
// 将obj的宽设置为当前screen的100%的高
lv_obj_set_size(img1, LV_PCT(50), LV_PCT(120));
```







![img](./img/rBJlJmfhAe2AKmwuAATcr5c255Q089.jpg)

### **2.2 针对不限图像场景**

修改`lv_conf.h`,使能相关宏定义（以JPG为例）：
![img](./img/rBJlJmfhAvWAYeNaAAFwIO_7Fvc158.jpg)



修改`lv_conf.h`，使能文件系统相关API函数：

`LV_FS_STDIO_LETTER`类似“盘符”，对嵌入式系统而言，可以任意设置一个大写字母，比如 ‘A’，那么后续图片路径均以A为虚拟盘符，比如 `A:/root/dog.jpg`

假设要显示开发板上的一张 `/root/dog.jpg `图片，可以修改官方示例代码：

## **3. 字体（Fonts）**

LVGL虽然有内置的字库，但对中文的支持非常鸡肋，直接放弃：

![img](./img/rBJlJmfhBVmADfLoAADlrDLHORE019.jpg)

在LVGL界面中使用中文，有两种方式：

1. 针对有限汉字场景，使用字库生成器，只生成所需要的汉字其余不要，节省内存空间
2. 针对不限汉字场景，使用第三方库freetype
    下面针对这两种不同的需求，列出操作步骤：

### **3.1 针对有限汉字场景**

首先打开[在线字库生成器](https://lvgl.io/tools/fontconverter)
![img](./img/rBJlJmfhBl6AFbrQAAD_LmtHIfw568.jpg)



1. 最后生成的字库名称，要符合C语言的标识符要求；
2. 字体大小，单位是像素；
3. 像素色深，越大字样显示越光滑，越小字样显示越锯齿，丰俭由人；
4. 选择普通ttf或woff字库文件；
5. 输入需要转化的汉字，注意数字也要一起转化，否则无法显示

然后，将导出的 `xxx.c `字库文件放入工程目录中，并修改 `CMakeLists.txt`：
![img](./img/rBJlJmfhBt-AUTgYAAEbNuv8f-Y961.jpg)



最后，在代码中使用字体：

```
// 声明字体
LV_FONT_DECLARE(simfang);
lv_btn_t * btn = lv_btn_create(lv_scr_act());
lv_label_t *label = lv_label_create(btn);
lv_label_set_text(label, "取消");
// 设置所用字体样式属性
lv_obj_set_style_text_font(label, &simfang, LV_PART_MAIN | LV_STATE_DEFAULT);
lv_obj_align(btn, LV_ALIGN_CENTER, 0, 0);
```







### **3.2 针对不限汉字场景**

修改`lv_conf.h`，找到宏`LV_USE_FREETYPE`，将其设置为1，使能freetype字体支持：
![img](./img/rBJlJmfhB2mAERAFAAFwXiQvW48370.jpg)



下载[freetype源码](http://edu.yueqian.com.cn/group1/M00/01/35/rBJlJmbrWi-AP8C_AEacC2KFds4885.zip?token=null&ts=null&filename=ft2133.zip)
在freetype源码顶层目录中，执行如下两条命令：

- export CC=arm-linux-gcc
- cmake -B build -D BUILD_SHARED_LIBS=true -D CMAKE_BUILD_TYPE=Release

确保能看到如下信息：
![img](./img/rBJlJmfhCBmAIWDOAADDdqV944w239.jpg)



在freetype顶层目录下，执行如下命令，编译freetype：`cmake --build build`
此时，会有如下头文件和库文件：

```
freetype-2.13.3/build/libfreetype.so.6.20.2
freetype-2.13.3/include/ft2build.h
```







然后，修改 lvgl 顶层 `CMakeLists.txt`：
![img](./img/rBJlJmfhCLOAPmXAAAJr5w1EZ6I890.jpg)



修改`main.c`，调用官方提供的freetype使用例程：
![img](./img/rBJlJmfhCPeAbjzPAAHoxUnirKs702.jpg)



修改官方提供的freetype例程：
![img](./img/rBJlJmfhCYiABAnBAANGLD1VYLc144.jpg)

上述代码中 `info.name = "./simfang.ttf" `是设置开发板中，字库 `simfang.ttf`的位置，要根据开发板的实际情况进行编写，不能照抄。

最后，将 libfreetype.so.6.20.2、simfang.ttf 传送到开发板，配好环境变量，运行main：

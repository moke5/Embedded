# 本机能力规范

> 定义本机工具如何被登记、调用与扩展，保证不同 agent 看到同一份事实。

## 1. 职责边界

| 文件 | 职责 | 读者 |
| --- | --- | --- |
| `能力清单.json` | 唯一的机器可读事实来源 | 调度脚本、AI |
| `能力/*.md` | 安装、参数、示例与常见问题 | 人 |
| `self/本机信息.md`、`self/移动端.md` | 本机与移动端信息（本地，不入库） | 人、AI |
| `script/adapters/*.ps1` | 统一接口的具体实现 | 调度器 |

清单与能力说明分离的理由：清单只保留机器决策所需的最小字段，说明文档承载人阅读的细节，两者不重复维护同一份信息。

## 2. 清单字段

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 唯一标识，小写英文与短横线，与适配器同名 |
| `name` | string | 显示名 |
| `summary` | string | 一句话说明能做什么 |
| `status` | enum | `ready` 可用 / `partial` 部分可用 / `planned` 规划中 |
| `adapter` | string | 相对仓库根的适配器路径 |
| `requires` | string[] | 依赖的命令或可执行文件 |
| `confirm` | bool | 执行前是否必须用户确认 |
| `tags` | string[] | 检索标签 |
| `examples` | string[] | 可复制的调用示例 |

## 3. 适配器契约

- 文件名固定为 `<id>.ps1`，放在 `script/adapters/`。
- 接收任意参数并原样转发，不做语义解释。
- 成功返回 0，失败返回非零。
- 依赖缺失时返回 127，并输出一条可执行的修复提示。
- 除本身需要交互的能力（如 `file-open` 的选择界面）外，不读取标准输入。
- 脚本文件保存为 UTF-8 with BOM，保证 Windows PowerShell 5.1 正确解析中文。

## 4. 新增能力流程

1. 在 `能力清单.json` 登记条目。
2. 编写 `script/adapters/<id>.ps1`。
3. 编写 `能力/<名>.md`，记录安装、参数、示例与坑。
4. 加入 `本机/MOC.md` 的内容索引。
5. 运行 `.\script\local.ps1 doctor` 验证依赖。

## 5. 隐私分层

- **入库**：能力清单、工具用法、适配器代码、通用命令。
- **不入库**（放 `self/`，已 gitignore）：本机硬件明细、移动端信息、IP、token、序列号、含用户名的绝对路径、设备唯一标识；敏感值统一写 `self/local.md`。
- `本机/` 只放能力清单与工具用法，不含个人信息；个人信息统一放 `self/`。

## 6. 禁止事项

- AI 不自动安装、下载或升级软件。
- AI 不修改系统环境变量，除非用户明确同意。
- AI 不把凭据写入清单、笔记或日志。
- AI 不为一次性任务另写临时脚本；应扩展适配器并登记。

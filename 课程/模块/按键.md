## **一、按键的硬件设计**

![img](./img/56388.png)

从按键的原理图可知，这些按键在没有被按下的时候，GPIO引脚的输入状态为高电平(接了上拉电阻)，当按键按下时， GPIO引脚的输入状态为低电平(按键所在的电路导通，引脚接到GND)。只要我们检测引脚的输入电平，即可判断按键是否被按下。

**2. 按键检测代码示例**

下面我们以KEY1为例，编写示例代码。由于要实时检测按键是否按下，我们需要不断地循环检测按键就应的芯片引脚电平，代码如下：

```C
while (1) 
{ 
    if (HAL_GPIO_ReadPin(KEY1_GPIO_Port, KEY1_Pin) == GPIO_PIN_RESET)    // 读取KEY1引脚电平，判断是否为低电平 
    {
        // KEY1引脚电平为低电平，翻转LED（LED引脚输出高则运行这行代码后变低，否则变高） 
        HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin); 
    }
}
```

 **3. 代码现象**

**3.** **1 预期现象**

1. 初始状态：LED灯处于熄灭状态

1. 按键操作：当按下连接到 PB12 的按键KEY1时（PB12 被拉低到低电平）LED状态会翻转：

- 如果LED原来是熄灭的 → 变为点亮

- 如果LED原来是点亮的 → 变为熄灭

 

**3.** **2 可能存在的问题**

1. 按键抖动：按键触发多次状态翻转

1. 响应速度：按键按下期间快速连续翻转LED状态

 

## **三、按键消抖**

按键机械触点断开、闭合时，由于触点的弹性作用，按键开关不会马上稳定接通或一下子断开，使用按键时会产生图中的带波纹信号。

![img](./img/56391.png)

为了能准确判断按键被按下，我们使用延时消抖方法（即检测到按键引脚的输入电平变化后延时[一般10~20ms]，再读取按键引脚的输入电平）判断按键是否被按下。

### SSH

1.SSH_config.tar.ba下载到开发板根目录



2.进入开发板根目录，解压缩，配置协议

```c
cd /
tar -xzvf SSH_config.tar.bz
cd SSH/openssh/
./auto
```



3.配置ssh密码

```c
passwd root
```



4.重启开发板

```c
reboot
```



5.Ubuntu下载ssh服务

```shell
sudo apt install openssh-server
```



6.检查是否启动：

```shell
sudo ps -e | grep ssh
```



```shell
sudo service ssh stat
```

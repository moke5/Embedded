# 微信开发者工具

## **一、安装微信开发者工具**

官网连接：[微信开发者工具下载](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)﻿

**1.1 下载安装包**

打开浏览器，访问微信官方文档提供的下载地址：

https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html﻿

![img](./img/56705.png)

点击对应按钮即可下载安装包。

## **二、项目创建**

安装并登录之后，你会进入项目列表页。下面将展示如何创建一个新项目。

**2.1 登录**

运行微信开发者工具，扫描二维码登录。

![img](./img/56706.png)

 

![img](./img/56707.png)

 

**2.2 填写项目信息**

1.在项目列表页，点击右侧的 **“新建项目”** 按钮（部分版本显示为“+”图标），进入项目创建向导。

![img](./img/56708.png)

 

2.进入新建项目页面后，需要依次填写以下内容。

![img](./img/56709.png)

① **项目名称**：给你的小程序起个名字，例如“wx_ble_app”。仅用于本地显示，不影响上线。

② **目录**：点击“选择”按钮，在电脑上指定一个**空文件夹**作为项目存放位置。

③ **AppID**：填入你在微信公众平台注册获得的 AppID。如果还没有，请点击右方的“测试号”，系统会自动分配一个临时 AppID 用于体验。正式项目一定要使用自己的 AppID。

④ **开发模式**：选择“小程序”。

⑤ **后端服务**：新手请选择“不使用云服务”，后续需要再开启。

所有信息确认无误后，点击右下角的 **“确定”**。

片刻之后，工具会自动打开新建的项目，此时界面一般分为工具栏、模拟器、目录树、编辑区和调试器五大区域。接下来我们就可以开始调试运行了。

## **四、常见问题与注意事项**

**1.新建项目按钮灰色无法点击？**

请确认选择的目录为空，或者非空目录下已存在 app.json/project.config.json 文件。

**2.模拟器与真机表现不一致？**

模拟器基于浏览器内核，与真实微信环境有差异，涉及原生组件或硬件能力时，请以真机结果为准。 

**3.启动工具后黑屏或白屏？**

可能是缺少 VC++ 运行库或 GPU 渲染问题，建议安装 Visual C++ 2015-2022 运行库并尝试在快捷方式中添加 --disable-gpu 参数。

**4.如何在其他电脑继续开发？**

使用 Git 管理项目代码，新电脑克隆后，在开发者工具中导入项目文件夹即可。

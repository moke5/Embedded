# 物料清单

[toc]



**BOM表在制造业和工程领域中是用于描述产品结构和所需物料的文档，它详细列出了构成最终产品的所有组件、部件和原材料，以及它们的数量和类型。**

**1.在菜单项【导出】选中“物料清单（BOM）”。**

![img](./img/56203.png)

**2.点击【导出BOM】。**

![img](./img/56204.png)

**3.打开excel表后，可看到元器件的数量与参数。**

![img](./img/56205.png)

**表格字段：**序号 No./ **数量 Quantity** / 物料名称 Comment / 位号 Designator / **封装 Footprint** / **参数 Value** / 料号 / **厂商** / 供应商

 

**4.生成BOM表后到淘宝货比三家配单报价。**

![img](./img/56206.png)

 

**5.店家沟通**

![img](./img/56207.png)

**6.付款后过几天就能够收到BOM表对应的元器件。**

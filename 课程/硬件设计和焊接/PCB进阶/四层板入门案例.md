**一、四层板结构**

**1.1 概述**

下方展示的是一块四层电路板，通常电路板的层数以双层递增，如2层、**4层**、6层等。四层板可以被理解为由两个双层板通过夹持一层绝缘基材而组成。这种结构设计增强了电路板的功能性和物理稳定性，**适用于复杂的电子设备中**。

![img](./img/55729.png)

四层板由**芯板**和**半固化片**压合而成，典型层叠结构如下：

| **层序**            | **类型**       | **功能说明**                              |
| ------------------- | -------------- | ----------------------------------------- |
| **顶层 (Top)**      | 信号层         | 主要布置元件和信号走线                    |
| **第二层 (Layer2)** | 内电层（负片） | 通常作为完整地平面（GND），提供低阻抗回路 |
| **第三层 (Layer3)** | 内电层（负片） | 通常作为电源平面（PWR），为各电源网络供电 |
| **底层 (Bottom)**   | 信号层         | 布置元件和信号走线                        |

**核心原则**：内电层（GND/PWR）与信号层（Top/Bottom）在设计规则、布线方式上完全不同，需分别理解。

 

**1.2 四层PCB板 vs 双层PCB板 优缺点对比**

**1.2.1 双层板（2层PCB：Top顶层 + Bottom底层）**

**优点**

1. **成本最低**：制版、打样、量产价格便宜，小批量、样机阶段性价比高

1. **工艺简单**：生产流程少、交期快，普通加工厂均可制作

1. **布线直观**：两层走线，新手调试、万用表测线路、飞线修改便捷

1. **板材厚度薄、柔性好**，适合简单低速外设、小型模块

**缺点**

1. **电源/地平面缺失**：电源线、地线只能走线，回路阻抗大、压降明显

1. **EMC/EMI性能差**：无完整参考地平面，高频信号容易串扰、辐射超标

1. **布线资源紧张**：复杂电路（多传感器、串口、电机、无线模块）容易走线拥挤，被迫绕线增加信号长度

1. **散热能力弱**：缺少大面积铜箔内层辅助散热

1. **不适合高速信号**：以太网、USB、高速SPI、WIFI/蓝牙射频信号完整性差

**1.2.2 四层板（4层PCB典型层叠：TOP信号层 → GND地层 → POWER电源层 → BOTTOM信号层）**

**优点**

1. **拥有完整独立地平面+电源平面**

回流路径短、阻抗低，电源纹波小，供电更稳定

1. **电磁兼容性（EMC/EMI）大幅提升**

内层地平面做屏蔽，抑制信号串扰、射频干扰，更容易过认证

1. **布线空间翻倍**，复杂嵌入式系统布线从容，走线更短、布局更规整

1. **散热性能更好**：内层整层铜箔辅助芯片散热

1. **信号完整性更强**，支持ESP32、WIFI、高速串口、以太网、高负载电路

1. **抗干扰能力强**：适合工业场景、智慧网关、AI终端、长期稳定工作的设备

**缺点**

1. **生产成本更高**：制版费用、打样费、量产单价高于双层板

1. **生产周期更长**，工艺要求更高

1. **内层线路无法直接肉眼查看**，调试排查故障难度高于双层板

1. **设计门槛更高**，需要掌握层叠规划、分割电源层、阻抗控制等知识

 

EMI（Electromagnetic Interference）电磁干扰电子设备产生无用电磁能量，对其他设备造成干扰，是干扰本身。分两类：传导干扰、辐射干扰。

EMC（Electromagnetic Compatibility）电磁兼容设备在电磁环境中，既能不对外产生超标干扰（EMI），又能抵抗外界干扰正常工作（EMS），设备共存互不影响。

**1.2.3 精简对比**

| **对比维度**      | **双层PCB**         | **四层PCB**               |
| ----------------- | ------------------- | ------------------------- |
| 制作成本          | 低                  | 较高                      |
| 布线资源          | 少，适合简单电路    | 充足，适配复杂系统        |
| 电源&地完整性     | 较差，走线式GND/VCC | 优良，完整平面            |
| EMC/抗干扰能力    | 弱                  | 强                        |
| 高速/无线信号适配 | 差                  | 优秀（ESP32、WIFI、射频） |
| 调试便捷性        | 高，直观可见        | 较低，内层不可视          |

 

**二、内电层与信号层的区别**

在嘉立创EDA（及大多数PCB设计工具）中，**内电层**和**信号层**是两种性质完全不同的铜层，它们在用途、电气特性、设计规则等方面有本质区别。

| **特性**     | **内电层**                                 | **信号层**                          |
| ------------ | ------------------------------------------ | ----------------------------------- |
| **用途**     | 专门用于电源/地网络，提供低阻抗回路        | 用于信号传输和元件连接              |
| **铜箔形式** | 整片铜箔，采用“负片”定义（无走线处为铜）   | 采用“正片”定义（画线处才有铜）      |
| **设计操作** | 只能分割区域，不能画线；新增过孔需重建避让 | 可自由走线、打孔、布置元件          |
| **阻抗特性** | 极低阻抗，适合大电流供电                   | 需手动控制阻抗（如差分线、50Ω单端） |
| **连接方式** | 通过过孔连接到电源/地引脚，自动避让        | 通过走线+过孔连接信号引脚           |

**3.1** **电源层设计原则**

电源层的核心价值是提供**低阻抗、连续的电源平面**，而非作为走线层使用。

| **设计要点**     | **说明**                                                     |
| ---------------- | ------------------------------------------------------------ |
| **电源网络处理** | 将3.3V、5V等电源引脚通过过孔直接连接到电源层，避免在信号层长距离走线 |
| **保持平面完整** | 电源层应尽量保持完整，仅在有多个不同电源时进行分割           |
| **接地层完整**   | 地平面应保持完整，避免分割，确保信号有连续的回流路径         |

**3.2** **信号层走线原则**

| **设计要点**     | **说明**                                                 |
| ---------------- | -------------------------------------------------------- |
| **优先表层走线** | 普通信号线优先在顶层和底层完成，减少层间切换             |
| **关键信号处理** | 时钟、高速差分等敏感信号应参考完整地平面，避免跨分割区域 |
| **过孔控制**     | 信号过孔引入寄生电容和电感，高速信号应尽量减少过孔数量   |

 

**3.3** **内电层重建操作**

**问题现象**：在已有铺铜的PCB上新增过孔后，DRC检测出现间距错误，原因是内电层（负片）未自动避让新过孔。

**解决方法**：在PCB设计工具中执行“**重建内电层**”操作，软件会重新生成负片层的避让区域，使新过孔与内电层正确隔离。

| **操作步骤** | **说明**                                    |
| ------------ | ------------------------------------------- |
| 1. 新增过孔  | 在需要的位置添加过孔                        |
| 2. 执行重建  | 在工具菜单中选择“重建内电层”                |
| 3. 验证结果  | 重建后，过孔在内电层中自动避让，DRC错误消除 |

**3.4 过孔类型与选型建议**

![img](./img/55738.png)

**通孔**（Plated Through Hole）作为最基础的互连形式，贯穿PCB所有层，孔径通常≥0.15mm。其主要承担双重职能：一是为插件元件（如电容、连接器）提供机械固定与电气连接；二是实现任意层间导通。但受限于结构特性，通孔在高速电路中易产生约0.5pF的寄生电容，可能引发信号延迟。

**盲孔**（Blind Via Hole）从表层延伸至内层但不穿透整板，孔径范围0.10–0.20mm。其核心价值在于节省表层布线空间，典型应用于手机主板等高密度互连（HDI）场景。例如折叠屏设备中，盲孔可将处理器BGA封装引脚直连至邻近信号层，布线间距压缩至0.2mm。但激光钻孔深度需精准控制（误差±10μm），否则可能击穿非目标铜层。

**埋孔**（Buried Via）完全隐藏于PCB内部，仅连接内层电路，孔径多控制在0.10–0.15mm。该技术通过规避表层空间占用，显著提升布线自由度，并降低高速信号串扰。在100G光模块等射频领域，埋孔能将敏感射频线与数字地隔离，使信号误码率降低3个数量级。其代价是制造成本增加30%以上，因需在内层压合前单独完成钻孔电镀。

 

**选型建议**：

- 常规设计：优先使用通孔，成本低、工艺成熟

- 高密度设计：在表层空间不足时，考虑使用盲孔

- 极高密度/射频设计：谨慎选用埋孔，需权衡成本与性能

**盲埋孔设计要点**：

- 在设计规则中设置盲埋孔的起始层与结束层（如“顶层—Layer3”）

- 过孔属性选择“盲埋孔”，类型对应设置的层组合

- 确认DRC无报错后，再提交生产

**四、总结**

| **最佳实践**             | **说明**                                                     |
| ------------------------ | ------------------------------------------------------------ |
| **层叠结构标准化**       | 采用“信号—地—电源—信号”标准四层结构，确保信号有完整回流路径。 |
| **内电层保持完整**       | 电源层和地层应尽量保持完整平面，避免分割影响供电质量和信号完整性。 |
| **新增过孔后重建内电层** | 在负片层中新增过孔后，必须执行重建操作，确保避让规则生效。   |
| **过孔选型由密度决定**   | 常规设计用通孔；高密度用盲孔；极高密度再考虑埋孔，需评估成本。 |
| **与板厂提前沟通**       | 盲埋孔设计需与PCB厂家确认工艺能力，避免设计无法实现。        |

# 差分信号线与等长布线

[toc]

**1.****单端信号与差分信号**

**1.单端信号**

所谓单端信号，指的是只用一根导线来发送信号。这种发送信号的方式非常简便。如果A芯片要给B芯片发送数据，那么它只需要将导线上的电平一会儿置高，一会儿置低就可以了

**单端信号传输示意图：**

![img](./img/55674.png)

单端信号传输方式主要适用于短距离的板上通信，而不宜用于线缆通信。这主要是因为单端信号的抗干扰能力较弱。例如，如果我们使用一根导线将电脑和单片机连接起来传输数据，而在此过程中如果不小心触碰了这根导线，可能会导致身上的静电释放到导线上。这种静电干扰可能会改变导线上的电平，从而导致接收端接收到错误的数据。

![img](./img/55675.png)

**2.差分信号**

为了克服单端信号易受干扰的问题，我们可以采用差分信号传输技术。这种技术涉及将发送端的原始信号转变为两个信号：D+ 和 D-。这两个信号通过两根导线传输，其中D+ 的波形与原始信号几乎相同，而 D- 是 D+ 的反相。这种方式可以显著增强信号的抗干扰能力。

**差分信号传输示意图：**

![img](./img/55676.png)

在接收端，信号的还原过程非常直接。系统通过比较 D+ 和 D- 两条线上的电压差来确定原始信号的状态。如果 D+ 的电压高于 D-，则认定为数字信号 "1"；相反，如果 D+ 的电压低于 D-，则认定为数字信号 "0"。

**双绞线：**

我们再将D+和D-两根导线绞在一起，这样它们就组成了双绞线。

![img](./img/55677.png)

在这种情况下，如果外部环境产生静电干扰，两根导线——D+和D-——会受到几乎相同的影响。这种干扰对两条线的影响是对称的，因此不会改变D+与D-之间的相对电压差。结果是，尽管存在干扰，接收端仍然能够准确地还原出发送端的原始信号。这展示了差分信号传输在保持数据完整性方面的强大能力，即使在高干扰的环境中也能维持信号的准确传输。

![img](./img/55678.png)

**2.****差分信号布线要求**

**1.尽量等长**

在传输电平变化时，信号在导线中的传递会有一定的延迟。为了确保信号的准确传输，差分布线的两根导线需要尽可能地保持等长。如果两根导线的长度不一致，会导致它们之间的延迟不一致，从而使接收端无法正确地还原发送端的信号。两根导线一定平行并且尽可能挨在一起。

**2.两根导线要平行地挨在一起**

这样做是因为D+和D-在线缆里的时候还是双绞线，能够确保外部干扰对两根导线是一致的。但是到了PCB上，如何走线就取决于工程师了。一般情况下，在PCB上，我们尽可能让两根线平行地挨在一起。提高两根线受到一致干扰的可能。

 

**3.** **差分布线操作步骤**

下面是在立创EDA进行差分布线的操作步骤：

**1.创建差分对**

（1）首先，在“设计”中找到“差分对管理器”。

![img](./img/55679.png)

（2）在“差分对管理器”中，先点击左上角的绿色+号。这个时候左下角的差分对列表会出现一个新的输入框，在这个位置你可以为新的差分对起一个名字。我们现在将它命名为DP1（DP是differential pair差分对的首字母）。

![img](./img/55680.png)

（3）差分对创建好后，为这个差分对制定正网络和负网络。选择好后，可以直接点击右下角的“确认”，这样差分对就创建好了。

![img](./img/55681.png)

（4）差分对创建成功后，在网络视图中就会出现刚刚创建的差分对。

![img](./img/55682.png)

**2.****差分对布线**

创建差分对之后，布线方式就不能再用传统的单线方法了。此时，需要在“布线”菜单中找到“差分对布线”选项。进入差分对布线模式，只需点击差分对中的任一网络，嘉立创EDA便会自动帮你实现平行布线。

![img](./img/55683.png)

**4.** **等长调节**

**1.差分对长度误差**

只需将D+和D-设置为一个差分对，当你调整布线时，光标附近便会显示如下图的误差示意图。按照默认的设计规则，差分对中两条导线的长度差应控制在±10mil以内。当你看到误差条变为绿色时，即表示你的设计符合此要求。

![img](./img/55686.png)

**2.等长调节**

如果误差条一直显示红色，说明两根导线的长度差异过大。此时，需要对差分线进行长度调节。在“布线”菜单栏中找到“等长调节”选项。

注意，这个操作能生效的前提是差分线已经被设定为差分对。

![img](./img/55687.png)

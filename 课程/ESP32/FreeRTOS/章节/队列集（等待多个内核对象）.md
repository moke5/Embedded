# 队列集（等待多个内核对象）

[toc]

**一、概述** 

队列集（Queue Set）是一种用于管理多个队列或信号量的机制，允许任务同时等待多个通信源的数据，提升多路复用效率。其核心作用、应用场景、实现机制及注意事项如下：

 

**1、队列集的核心作用：**

- 多路复用监听任务可同时阻塞在多个队列或信号量上，任一被监听的队列有数据时，任务立即被唤醒，无需轮询每个队列。

- 简化事件处理逻辑替代为每个队列单独创建任务的复杂设计，通过统一监听队列集，集中处理多源事件，降低代码耦合度。

- **资源高效利用避免任务频繁切换或忙等待，减少CPU占用，提升实时响应能力。**

 

**2、典型应用场景：**

- **多传感器数据采集**任务需从多个传感器（如温度、湿度、加速度计）接收数据，每个传感器对应一个队列。队列集使任务能同时监听所有传感器队列，任一数据到达即可处理。

- **网络通信多路复用服务器**任务需处理多个客户端请求，每个客户端通过独立队列通信。队列集可监听所有客户端队列，及时响应任意活跃连接。

- **混合事件处理任务**需同时处理用户输入（如按键队列）、定时器事件（通过信号量）和数据包接收（另一个队列）。队列集统一监听这些异构事件源。

- **优先级动态切换**高优先级任务需在多个紧急事件源（如错误告警、关键指令）中选择处理，队列集确保最先到达的事件被优先响应。

 

**3、实现机制与注意事项**

**1.创建与绑定**

- 使用 xQueueCreateSet() 显式创建队列集。

- 通过 xQueueAddToSet() 将队列或信号量加入集合。

**2.阻塞与唤醒**

- 任务调用 xQueueSelectFromSet() 阻塞，直到任一队列有数据。

- 唤醒后遍历队列集，找到就绪的队列并读取数据。

**3.性能考量**

- 队列集本身有内存开销，需合理控制监听队列数量。

- 避免高频小数据量场景（可能引发频繁任务切换）。

**4.限制**

- 仅支持队列、二值信号量、计数信号量。

- 不支持同时等待多个事件标志组、互斥锁

- 一个队列只能加入一个队列集。

 

**4、与事件组的区别**

| **特性**     | **队列集**             | **事件组**               |
| ------------ | ---------------------- | ------------------------ |
| **监听对象** | 队列、信号量           | 任意事件（通过位标志）   |
| **数据传递** | 可传输数据（通过队列） | 仅同步（无数据传输）     |
| **资源消耗** | 较高（需维护队列集合） | 较低（位操作）           |
| **适用场景** | 多源数据接收           | 多任务同步或复杂状态管理 |

 

**💡总结**

队列集适用于需**集中监听多个数据源**的场景，如物联网设备的多传感器管理或服务器的多客户端通信。其通过简化多路阻塞逻辑，提升系统响应效率，但需权衡资源开销与设计复杂度。在仅需事件同步（无需数据传输）时，事件组可能是更轻量级的选择。

 

**二、函数接口**

 

**2.1 创建队列集**

```
QueueSetHandle_t xQueueCreateSet（const UBaseType_t uxEventQueueLength）;
```

**在FreeRTOS.h中，必须将****configUSE_QUEUE_SETS****设置为****1****才能使xQueueCreateSet（）API函数可用。**

队列集提供了一种机制，允许RTOS任务同时阻止（挂起）来自多个RTOS队列或信号量的读取操作。请注意，使用队列集有更简单的替代方法。

必须先使用对xQueueCreateSet（）的调用显式创建队列集，然后才能使用它。创建后，可以使用对xQueueAddToSet（）的调用将标准FreeRTOS队列和信号量添加到集合中。然后使用xQueueSelectFromSet（）来确定集合中包含的队列或信号量中的哪一个（如果有）处于队列读取或信号量获取操作成功的状态。

 

注意：

将队列和信号量添加到队列集时，它们必须为空。阻止包含互斥锁的队列集不会导致互斥锁持有者继承被阻止任务的优先级。添加到队列集的每个队列中的每个空间都需要额外的4个字节的RAM。因此，不应将具有高最大计数值的计数信号量添加到队列集。除非对xQueueSelectFromSet（）的调用首先返回该set成员的句柄，否则不得对队列集的成员执行接收（在队列的情况下）或take（在信号量的情况下）操作。

 

参数：

uxEventQueueLength 队列设置存储在集合中包含的队列和信号量上的事件。 uxEventQueueLength指定一次可以排队的最大事件数。

为了绝对确定事件没有丢失，必须将uxEventQueueLength设置为添加到集合的队列长度的总和，其中二值信号量和互斥量的长度为1，计数信号量的长度由其最大计数值设置。例如：

如果队列集要保存长度为5的队列，另一个长度为12的队列和一个二值信号量，则uxEventQueueLength应设置为（5 + 12 + 1）或18。

如果队列集要保存三个二值信号量，则uxEventQueueLength应设置为（1 + 1 + 1）或3。

如果队列集要保存最大计数为5的计数信号量，以及最大计数为3的计数信号量，则uxEventQueueLength应设置为（5 + 3）或8。

 

返回：

如果成功创建了队列集，则返回创建的队列集的句柄。否则返回NULL。

 

**2.2 将信号量或消息队列添加到队列集**

```
BaseType_t xQueueAddToSet（QueueSetMemberHandle_t xQueueOrSemaphore，QueueSetHandle_t xQueueSet）;
```

**在FreeRTOS.h中，必须将****configUSE_QUEUE_SETS****设置为****1****才能使xQueueCreateSet（）API函数可用。**

将RTOS队列或信号量添加到先前通过调用xQueueCreateSet（）创建的队列集。

 

参数：

xQueueOrSemaphore-要添加到队列集的队列或信号量的句柄（强制转换为QueueSetMemberHandle_t类型）。

xQueueSet-要添加队列或信号量的队列集的句柄。

 

返回：

如果队列或信号量已成功添加到队列集，则返回pdPASS。如果队列无法成功添加到队列集，因为它已经是不同队列集的成员，则返回pdFAIL。

 

 

**2.3 从队列成员中选择一个队列或信号量**

```
QueueSetMemberHandle_t xQueueSelectFromSet（QueueSetHandle_t xQueueSet，const TickType_t xTicksToWait）;
```

**在FreeRTOS.h中，必须将****configUSE_QUEUE_SETS****设置为****1****才能使xQueueSelectFromSetFrom（）API函数可用。**

xQueueSelectFromSet（）从队列成员中选择一个队列或信号量，该队列或信号量包含数据（在队列的情况下）或可用于（在信号量的情况下）。 xQueueSelectFromSet（）有效地允许任务同时阻塞（挂起）队列集中所有队列和信号量的读操作。

 

参数：

xQueueSet 任务将（可能）阻止的队列集。

xTicksToWait 调用任务将保持在阻塞状态（其他任务正在执行）的最长时间（以时钟周期为单位），以等待队列集的成员为成功的队列读取或信号量执行操作做好准备。

 

返回：

xQueueSelectFromSet（）将返回包含在包含数据的队列集中的队列句柄（强制转换为QueueSetMemberHandle_t类型），或者返回包含在可用队列集中的信号量句柄（强制转换为QueueSetMemberHandle_t类型），或者为NULL如果在指定的块时间到期之前没有这样的队列或信号量。

 

**2.4 从中断服务例程（ISR）使用的xQueueSelectFromSet**

```
QueueSetMemberHandle_t xQueueSelectFromSetFromISR（QueueSetHandle_t xQueueSet）;
```

**在FreeRTOS.h中，必须将****configUSE_QUEUE_SETS****设置为****1****才能使xQueueSelectFromSetFromISR（）API函数可用。**

可以从中断服务例程（ISR）使用的xQueueSelectFromSet（）版本。

 

参数：

xQueueSet正在查询的队列集。 由于此功能旨在用于中断，因此无法阻止读取。

 

返回：

xQueueSelectFromSetFromISR（）将返回包含数据的队列集中包含的队列句柄（强制转换为QueueSetMemberHandle_t类型），或者返回包含在可用队列集中的信号量句柄（强制转换为QueueSetMemberHandle_t类型），或者为NULL 如果不存在这样的队列或信号量。

 

 

**2.5 从队列集中删除RTOS队列或信号量**

```
BaseType_t xQueueRemoveFromSet（QueueSetMemberHandle_t xQueueOrSemaphore，QueueSetHandle_t xQueueSet）;
```

**在FreeRTOS.h中，必须将****configUSE_QUEUE_SETS****设置为****1****才能使xQueueRemoveFromSet（）API函数可用，如下图。**

参数：

xQueueOrSemaphore 从队列集中删除的队列或信号量的句柄（强制转换为QueueSetMemberHandle_t类型）。

xQueueSet 包含队列或信号量的队列集的句柄。

 

返回：

如果从队列集中成功删除了队列或信号量，则返回pdPASS。 如果队列不在队列集中，或者队列（或信号量）不为空，则返回pdFAIL。

 

**三、示例代码**

 

**main.c** 

```
/* 声明任务1的句柄，用于任务控制 */
static TaskHandle_t app_task1_handle = NULL;
/* 声明任务2的句柄，用于任务控制 */
static TaskHandle_t app_task2_handle = NULL;
/* 声明任务1函数原型 */
static void app_task1(void *pvParameters);
/* 声明任务2函数原型 */
static void app_task2(void *pvParameters);
/* 定义队列长度为4，即最多可存储4个消息 */
#define QUEUE_LEN 4
/* 定义每个消息的大小为64字节 */
#define QUEUE_SIZE 64
/* 声明消息队列句柄 */
QueueHandle_t xQueue = NULL;
/* 声明二值信号量句柄 */
static QueueHandle_t BinarySemaphore;
/* 声明计数型信号量句柄 */
static SemaphoreHandle_t CountSemaphore;
/* 定义二值信号量在队列集中的长度为1 */
#define BINARY_SEMAPHORE_LENGTH 1
/* 定义计数信号量在队列集中的长度为5 */
#define COUNT_SEMAPHORE_LENGTH 5
/* 计算队列集的总长度（队列长度+二值信号量长度+计数信号量长度） */
#define COMBINED_LENGTH (QUEUE_LEN + BINARY_SEMAPHORE_LENGTH + COUNT_SEMAPHORE_LENGTH)
/* 声明消息队列集合句柄 */
static QueueSetHandle_t xQueueSet;
/* 主函数入口 */
int main(void)
{
    /* 设置NVIC中断优先级分组为第4组 */
    NVIC_PriorityGroupConfig(NVIC_PriorityGroup_4);
    /* 配置系统滴答定时器，设置中断频率为FreeRTOS配置的时钟节拍频率 */
    SysTick_Config(SystemCoreClock / configTICK_RATE_HZ);
    /* 初始化串口通信，波特率为9600 */
    uart_init(9600);
    /* 创建任务1 (app_task1) */
    xTaskCreate((TaskFunction_t)app_task1,          /* 任务函数指针 */
                (const char *)"app_task1",          /* 任务名称 */
                (uint16_t)512,                      /* 任务堆栈大小 */
                (void *)NULL,                       /* 任务参数 */
                (UBaseType_t)4,                     /* 任务优先级 */
                (TaskHandle_t *)&app_task1_handle); /* 任务句柄 */
    /* 创建任务2 (app_task2) */
    xTaskCreate((TaskFunction_t)app_task2,          /* 任务函数指针 */
                (const char *)"app_task2",          /* 任务名称 */
                (uint16_t)512,                      /* 任务堆栈大小 */
                (void *)NULL,                       /* 任务参数 */
                (UBaseType_t)5,                     /* 任务优先级 */
                (TaskHandle_t *)&app_task2_handle); /* 任务句柄 */
    /* 创建消息队列集合，指定集合总长度 */
    xQueueSet = xQueueCreateSet(COMBINED_LENGTH);
    /* 创建消息队列，指定队列长度和消息大小 */
    xQueue = xQueueCreate((UBaseType_t)QUEUE_LEN,   /* 队列长度 */
                          (UBaseType_t)QUEUE_SIZE); /* 消息大小 */
    /* 检查队列是否创建成功 */
    if (NULL == xQueue)
        printf("创建xQueue消息队列失败!\r\n");
    /* 创建二值信号量 */
    BinarySemaphore = xSemaphoreCreateBinary();
    /* 创建计数信号量，最大计数值为5，初始值为0 */
    CountSemaphore = xSemaphoreCreateCounting(5, 0);
    /* 将消息队列添加到队列集合中 */
    xQueueAddToSet(xQueue, xQueueSet);
    /* 将二值信号量添加到队列集合中 */
    xQueueAddToSet(BinarySemaphore, xQueueSet);
    /* 将计数信号量添加到队列集合中 */
    xQueueAddToSet(CountSemaphore, xQueueSet);
    /* 启动FreeRTOS任务调度器 */
    vTaskStartScheduler();
    /* 无限循环，防止主函数退出 */
    while (1)
        ;
}
/* 任务1函数实现 */
static void app_task1(void *pvParameters)
{
    /* 声明错误状态变量 */
    BaseType_t err = pdFALSE;
    /* 无限循环 */
    for (;;)
    {
        /* 打印任务运行信息 */
        printf("[app_task1] is running ...\r\n");
        /* 释放二值信号量 */
        xSemaphoreGive(BinarySemaphore);
        /* 延时3000个时钟节拍 */
        vTaskDelay(3000);
        /* 释放计数信号量三次 */
        xSemaphoreGive(CountSemaphore);
        xSemaphoreGive(CountSemaphore);
        xSemaphoreGive(CountSemaphore);
        /* 延时3000个时钟节拍 */
        vTaskDelay(3000);
    }
}
/* 任务2函数实现 */
static void app_task2(void *pvParameters)
{
    /* 声明接收状态变量 */
    BaseType_t xReturn = pdFALSE;
    /* 定义接收缓冲区 */
    uint8_t buf[QUEUE_SIZE] = {0};
    /* 声明激活成员句柄 */
    QueueSetMemberHandle_t xActivatedMember;
    /* 无限循环 */
    for (;;)
    {
        /* 从队列集中选择已激活的成员，等待时间为无限 */
        xActivatedMember = xQueueSelectFromSet(xQueueSet,
                                               portMAX_DELAY);
        /* 判断激活的成员是否为消息队列 */
        if (xActivatedMember == xQueue)
        {
            /* 从消息队列接收数据，不等待 */
            xReturn = xQueueReceive(xActivatedMember, /* 队列句柄 */
                                    buf,              /* 接收缓冲区 */
                                    0);               /* 等待时间 */
            /* 检查接收是否成功 */
            if (pdTRUE == xReturn)
                printf("[app_task2]本次接收到的数据是%s\r\n", buf);
            else
                printf("[app_task2]数据接收出错,错误代码0x%lx\n", xReturn);
            /* 清空缓冲区 */
            memset(buf, 0, sizeof buf);
        }
        /* 判断激活的成员是否为二值信号量 */
        else if (xActivatedMember == BinarySemaphore)
        {
            /* 获取二值信号量，不等待 */
            xSemaphoreTake(xActivatedMember, 0);
            /* 打印获取信号量信息 */
            printf("[app_task2] get binary semaphore\r\n");
        }
        /* 判断激活的成员是否为计数信号量 */
        else if (xActivatedMember == CountSemaphore)
        {
            /* 获取计数信号量，不等待 */
            xSemaphoreTake(xActivatedMember, 0);
            /* 打印获取信号量信息 */
            printf("[app_task2] get count semaphore\r\n");
        }
    }
}
```

 

**usart.c**

```C
static volatile uint8_t  	g_usart1_recv_buf[64]={0};
static volatile uint32_t 	g_usart1_recv_cnt = 0;
 
extern QueueHandle_t xQueue;
 
//串口1中断服务程序
void USART1_IRQHandler(void)                	
{
	uint8_t d;
	
	uint32_t ulReturn;
	
	BaseType_t xHigherPriorityTaskWoken;
	
	/* 进入临界段，临界段可以嵌套 */
	ulReturn = taskENTER_CRITICAL_FROM_ISR();	
	
	if(USART_GetITStatus(USART1, USART_IT_RXNE) != RESET)  
	{
		//接收串口数据
		d=USART_ReceiveData(USART1);
 
		g_usart1_recv_buf[g_usart1_recv_cnt]=d;
		
		//记录多少个数据
		g_usart1_recv_cnt++;
		
		//检测到'#'符或接收的数据满的时候则发送数据
		if(d=='#' || g_usart1_recv_cnt>=(sizeof g_usart1_recv_buf))
		{
#if 0
			xQueueSendFromISR(xQueue,(void *)g_usart1_recv_buf,NULL);
#else
			xQueueSendFromISR(xQueue,(void *)g_usart1_recv_buf,&xHigherPriorityTaskWoken);
			memset((void *)g_usart1_recv_buf,0,sizeof g_usart1_recv_buf);
#endif			
			g_usart1_recv_cnt=0;
		}			
		
		//清空串口接收中断标志位
		USART_ClearITPendingBit(USART1, USART_IT_RXNE);
	} 
	
	
	/* 若接收消息队列任务的优先级高于当前运行的任务，则退出中断后立即进行任务切换，执行前者;
	   否则等待下一个时钟节拍才进行任务切换
	*/
    if( xHigherPriorityTaskWoken )
    {
		
        portYIELD_FROM_ISR( xHigherPriorityTaskWoken );
    }	
	
	/* 退出临界段 */
	taskEXIT_CRITICAL_FROM_ISR( ulReturn );	
	
} 
```

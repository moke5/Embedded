# 音频输出

[toc]



## **一、ES8311音频解码芯片**

ES8311 是一款低功耗、高性能的立体声音频编解码器（Audio Codec），专为便携式和嵌入式音频应用设计，非常适合与 ESP32-S3 等微控制器配合使用，实现语音采集、播放和通信功能。

开发板上使用 **ES8311 作为音频输出控制芯片**，ES8311 的输出，同时接到了 ES7210 的 MIC3 和音频功放芯片。本例程，实现播放一小段格式为 PCM 的音乐，后面的例程，我们会学习播放 MP3 格式的音乐。

**1.1 核心特性概述**

1. 音频性能：

- ADC：信噪比（SNR）高达 **100dB**，总谐波失真加噪声（THD+N）低至 **-93dB**，适合高质量录音。

- DAC：信噪比高达 **110dB**，THD+N 为 **-80dB**，支持高质量音频输出。

- 支持 24-bit 精度，采样率范围 **8 kHz 到 96 kHz**。

1. 接口与连接：

- 数字音频接口：支持标准的 **I²S** 和 **PCM** 格式。可直接与 ESP32-S3 的 I2S 外设相连，用于传输录音数据（ASDOUT）和播放数据（DSDIN）。

- 控制接口：**I²C** 接口（引脚 CCLK， CDATA），用于配置 ES8311 的内部寄存器（如音量、采样率、ALC 等）。ESP32-S3 可通过 I2C 主模式对其进行完全控制。

- 时钟模式：可作为 **Master** 或 **Slave** 工作，支持多种主时钟频率（256/384Fs， USB 12/24 MHz 等），时钟适配灵活。

1. 模拟特性：

- 输入：支持一对差分或单端模拟输入（MIC1P/N），内置低噪声前置放大器、自动电平控制（ALC）和噪声门。

- 输出：支持一对差分或单端模拟输出（OUTP/N），带有耳机驱动能力。

- 其他：内置动态范围压缩、爆音与咔嗒声抑制电路，提升音频体验。

1. 功耗与电源：

- 工作电压范围宽（**1.8V 至 3.3V**），可与 ESP32-S3 的 I/O 电压（通常为 3.3V）直接连接。

- 低功耗设计，回放与录音模式下功耗仅为**14 mW**，待机电流极低，适合电池供电的物联网音频设备。

**1.2 与 ESP32-S3 开发要点**

- 硬件连接：

- I2S 总线：将 ES8311 的 MCLK、SCLK、LRCK、ASDOUT、DSDIN 连接到 ESP32-S3 的 I2S 控制器引脚。

- I²C 总线：将 CCLK、CDATA 连接到 ESP32-S3 的 I2C 引脚，用于寄存器配置。

- 电源：注意 AVDD、DVDD、PVDD 的供电要求（典型 3.3V），并按照数据手册要求放置去耦电容（如 10µF + 0.1µF）。

- 软件开发：

- ESP32-S3 端需要编写 I2C 驱动来初始化 ES8311（设置采样率、格式、增益等）。

- 使用 ESP32-S3 的 I2S 驱动库进行音频数据的 DMA 传输，实现低延迟录音和播放。

- 参考 ES8311 数据手册中的寄存器映射表进行配置（如时钟分频器、ALC 参数等）。

**1.3 典型应用场景**

- 网络摄像头 / 行车记录仪

- 双向对讲设备（门铃、婴儿监视器）

- 录音笔 / 语音助手

- 需要语音交互的 IoT 设备

MCLK 是 ES8311 这类编解码器**内部的"心脏时钟"**。编解码器里不是简单地把数字信号变成模拟信号，它内部有：

- Σ-Δ（Sigma-Delta）调制器，工作在远高于采样率的高频上（过采样）

- 数字滤波器、抽取/内插引擎

- 内部 PLL 和分频器

这些电路都需要一个**高频率、稳定的参考时钟**才能运转， MCLK 必须和采样率成固定整数倍（256/384/512），分频表才能精确命中，并表现在es8311.c中的coeff_div结构体数组。

NS4150B 是一款3.0W 单声道 D 类音频功率放大器，其主要作用是将来自音频编解码器（如 ES8311）的模拟音频信号进行功率放大，从而驱动扬声器发出声音。

 

**核心作用：驱动扬声器**

- ES8311 的局限性：ES8311 虽然内置了耳机驱动，但其输出功率较小（通常用于驱动 16Ω、32Ω 耳机），无法直接驱动功率扬声器（4Ω 或 8Ω）。

- NS4150B 的功能：它接收来自 ES8311 的模拟音频输出，将其放大到足够的功率（例如在 5V 供电下，可向 4Ω 负载输出 **2.8W** 的功率），从而让扬声器发出响亮的声音。

**电路中的连接方式**

1. 输入：NS4150B 的 **INP**（正极）和 **INN**（负极）引脚接收来自 ES8311 的 **OUTP** 和 **OUTN** 的模拟音频输出。

1. 控制：**CTRL** 引脚连接到 ESP32-S3 的 GPIO，用于控制音频输出的开启（高电平）和关闭（低电平/Shutdown 模式），以实现省电或静音。

1. 输出：**VoP** 和 **VoN** 直接连接到扬声器的两个接线端。

## **三、软件设计**

**3.1 调用时序流程图**

```
app_main()
├─ i2c_init() → I2C0总线就绪
├─ pca9557_init() → IO扩展芯片就绪
├─ i2s_driver_init()
│   ├─ I2S_CHANNEL_DEFAULT_CONFIG 创建发送通道tx_handle，auto_clear=true
│   ├─ i2s_new_channel() 创建I2S通道
│   ├─ i2s_std_config_t配置：16kHz、16bit立体声、MCLK*384、GPIO引脚
│   ├─ i2s_channel_init_std_mode(tx_handle,&std_cfg)
│   └─ i2s_channel_enable(tx_handle) 使能I2S硬件
├─ es8311_codec_init()
│   ├─ i2c_master_bus_add_device() 将ES8311挂载到I2C0
│   ├─ I2C写寄存器0x00执行软复位，延时20ms
│   └─ 遍历es8311_init_seq，写ES8311全部初始化寄存器
├─ pca9557_set_output_state(1,1) → IO1置高，打开音频功放PA_EN
└─ i2s_music_task_start() 创建i2s_music播放任务
    └─i2s_music()任务循环
        ├─i2s_channel_disable(tx_handle) 关闭通道
        ├─i2s_channel_preload_data()预加载首段pcm数据进DMA
        ├─i2s_channel_enable(tx_handle)打开I2S通道
        └─while(1)
            ├─i2s_channel_write()把Flash内嵌pcm数据送入I2S‑DMA
            ├─播放完成重置data_ptr回到pcm起始
            └─vTaskDelay(1000ms)延时，循环播放
 
```

**3.3 数据流路径**

```
Flash（固件内嵌 canon.pcm s16le 16k 立体声）
        ↓内存直接访问 music_pcm_start[]
i2s_music任务（CPU读取Flash数据）
        ↓ i2s_channel_write()，数据拷贝进I2S DMA缓冲区
I2S外设DMA硬件
        ↓硬件输出 MCLK / BCLK / WS / DOUT
ES8311(I2S从设备)
        ↓Codec内部DAC模拟转换
耳机/扬声器（功放由PCA9557的PA_EN控制开关）
```

**3.3 核心函数**

**3.3.1 es8311_codec_init() - ES8311编解码器初始化**

```
// 初始化I2C接口 并初始化es8311芯片
static esp_err_t es8311_codec_init(void)
{
    /* 初始化I2C接口 */
    // 初始化开发板I2C接口
    ESP_ERROR_CHECK(bsp_i2c_init());
 
    /* 初始化es8311芯片 */
    // 创建ES8311编解码器句柄，指定I2C编号和设备地址
    es8311_handle_t es_handle = es8311_create(BSP_I2C_NUM, ES8311_ADDRRES_0);
    // 检查ES8311句柄是否创建成功，失败则返回错误
    ESP_RETURN_ON_FALSE(es_handle, ESP_FAIL, TAG, "es8311 create failed");
    // 配置ES8311时钟参数
    const es8311_clock_config_t es_clk = {
        // 主时钟不反相
        .mclk_inverted = false,
        // 位时钟不反相
        .sclk_inverted = false,
        // 主时钟来自MCLK引脚
        .mclk_from_mclk_pin = true,
        // 设置主时钟频率
        .mclk_frequency = EXAMPLE_MCLK_FREQ_HZ,
        // 设置采样频率
        .sample_frequency = EXAMPLE_SAMPLE_RATE
    };
 
    // 初始化ES8311编解码器，设置时钟配置和16位分辨率
    ESP_ERROR_CHECK(es8311_init(es_handle, &es_clk, ES8311_RESOLUTION_16, ES8311_RESOLUTION_16));
    // 配置ES8311采样频率，失败则返回错误
    ESP_RETURN_ON_ERROR(es8311_sample_frequency_config(es_handle, EXAMPLE_SAMPLE_RATE * EXAMPLE_MCLK_MULTIPLE, EXAMPLE_SAMPLE_RATE), TAG, "set es8311 sample frequency failed");
    // 设置ES8311音量，失败则返回错误
    ESP_RETURN_ON_ERROR(es8311_voice_volume_set(es_handle, EXAMPLE_VOICE_VOLUME, NULL), TAG, "set es8311 volume failed");
    // 配置ES8311麦克风，禁用麦克风，失败则返回错误
    ESP_RETURN_ON_ERROR(es8311_microphone_config(es_handle, false), TAG, "set es8311 microphone failed");
 
    // 返回成功状态码
    return ESP_OK;
}
```

功能说明 ：初始化I2C接口和ES8311音频编解码器芯片

执行流程 ：

1. 初始化I2C接口 ：调用 bsp_i2c_init() 初始化开发板的I2C总线

1. 创建ES8311句柄 ：使用 es8311_create() 创建编解码器实例，指定I2C编号和设备地址

1. 配置时钟参数 ：设置主时钟(MCLK)、位时钟(SCLK)的极性和频率

1. 初始化ES8311 ：调用 es8311_init() 配置采样率和分辨率（16位）

1. 设置采样频率 ：配置MCLK倍数和实际采样率

1. 设置音量 ：设置播放音量

1. 配置麦克风 ：禁用麦克风功能（本例只播放音频）

关键参数 ：

- EXAMPLE_MCLK_FREQ_HZ ：主时钟频率

- EXAMPLE_SAMPLE_RATE ：采样率（如44.1kHz）

- EXAMPLE_MCLK_MULTIPLE ：MCLK倍数（如256）

- EXAMPLE_VOICE_VOLUME ：音量值

 

**3.3.2 i2s_driver_init() - I2S驱动初始化**

```C
// 初始化I2S外设
static esp_err_t i2s_driver_init(void)
{
    /* 配置i2s发送通道 */
    // 创建I2S通道默认配置，指定I2S编号和主模式
    i2s_chan_config_t chan_cfg = I2S_CHANNEL_DEFAULT_CONFIG(I2S_NUM, I2S_ROLE_MASTER);
    // 设置自动清除标志，自动清除DMA缓冲区中的旧数据
    chan_cfg.auto_clear = true; // Auto clear the legacy data in the DMA buffer
    // 创建新的I2S通道，只创建发送通道，接收通道为NULL
    ESP_ERROR_CHECK(i2s_new_channel(&chan_cfg, &tx_handle, NULL));
    /* 初始化i2s为std模式 并打开i2s发送通道 */
    // 配置I2S标准模式参数
    i2s_std_config_t std_cfg = {
        // 配置I2S时钟，使用默认配置和采样率
        .clk_cfg = I2S_STD_CLK_DEFAULT_CONFIG(EXAMPLE_SAMPLE_RATE),
        // 配置I2S时隙，使用16位数据宽度和立体声模式
        .slot_cfg = I2S_STD_PHILIPS_SLOT_DEFAULT_CONFIG(I2S_DATA_BIT_WIDTH_16BIT, I2S_SLOT_MODE_STEREO),
        // 配置I2S GPIO引脚
        .gpio_cfg = {
            // 设置主时钟引脚
            .mclk = I2S_MCK_IO,
            // 设置位时钟引脚
            .bclk = I2S_BCK_IO,
            // 设置字选择时钟引脚
            .ws = I2S_WS_IO,
            // 设置数据输出引脚
            .dout = I2S_DO_IO,
            // 设置数据输入引脚
            .din = I2S_DI_IO,
            // 配置引脚反相标志
            .invert_flags = {
                // 主时钟不反相
                .mclk_inv = false,
                // 位时钟不反相
                .bclk_inv = false,
                // 字选择时钟不反相
                .ws_inv = false,
            },
        },
    };
    // 设置主时钟倍数
    std_cfg.clk_cfg.mclk_multiple = EXAMPLE_MCLK_MULTIPLE;
 
    // 初始化I2S通道为标准模式
    ESP_ERROR_CHECK(i2s_channel_init_std_mode(tx_handle, &std_cfg));
    // 使能I2S发送通道
    ESP_ERROR_CHECK(i2s_channel_enable(tx_handle));
 
    // 返回成功状态码
    return ESP_OK;
}
```

功能说明 ：初始化I2S外设，配置为标准模式用于音频数据传输

执行流程 ：

1. 创建I2S通道 ：

- 配置为主模式（I2S_ROLE_MASTER）

- 启用自动清除功能（auto_clear=true），自动清除DMA缓冲区旧数据

- 只创建发送通道（tx_handle），不创建接收通道

1. 配置I2S标准模式 ：

- 时钟配置 ：设置采样率

- 时隙配置 ：16位数据宽度，立体声模式

- GPIO配置 ：配置MCLK、BCLK、WS、DOUT、DIN引脚

- 时钟倍数 ：设置MCLK倍数

1. 初始化并使能通道 ：

- 调用 i2s_channel_init_std_mode() 初始化标准模式

- 调用 i2s_channel_enable() 使能发送通道

- MCLK ：主时钟，提供系统时钟

- BCLK ：位时钟，同步数据传输

- WS ：字选择时钟，区分左右声道

- DOUT ：数据输出，发送音频数据到编解码器

- DIN ：数据输入，接收音频数据（本例未使用）

 

**3.3.3 i2s_music()-音乐播放任务**

```C
// 音乐播放任务函数
static void i2s_music(void *args)
{
    // 定义错误状态变量，初始化为成功
    esp_err_t ret = ESP_OK;
    // 定义已写入字节数变量，初始化为0
    size_t bytes_write = 0;
    // 定义数据指针，指向音乐PCM数据起始地址
    uint8_t *data_ptr = (uint8_t *)music_pcm_start;
 
    /* (Optional) Disable TX channel and preload the data before enabling the TX channel,
     * so that the valid data can be transmitted immediately */
    // 禁用I2S发送通道
    ESP_ERROR_CHECK(i2s_channel_disable(tx_handle));
    // 预加载数据到DMA缓冲区，使能通道后可以立即传输有效数据
    ESP_ERROR_CHECK(i2s_channel_preload_data(tx_handle, data_ptr, music_pcm_end - data_ptr, &bytes_write));
    // 移动数据指针，跳过已预加载的数据
    data_ptr += bytes_write;  // Move forward the data pointer
 
    /* Enable the TX channel */
    // 使能I2S发送通道
    ESP_ERROR_CHECK(i2s_channel_enable(tx_handle));
    // 进入无限循环，持续播放音乐
    while (1) {
        /* Write music to earphone */
        // 将音乐数据写入I2S通道，使用最大延迟等待
        ret = i2s_channel_write(tx_handle, data_ptr, music_pcm_end - data_ptr, &bytes_write, portMAX_DELAY);
        // 检查写入操作是否成功
        if (ret != ESP_OK) {
            /* Since we set timeout to 'portMAX_DELAY' in 'i2s_channel_write'
               so you won't reach here unless you set other timeout value,
               if timeout detected, it means write operation failed. */
            // 打印错误日志，显示I2S写入失败的原因
            ESP_LOGE(TAG, "[music] i2s write failed, %s", err_reason[ret == ESP_ERR_TIMEOUT]);
            // 终止程序
            abort();
        }
        // 检查是否有数据写入
        if (bytes_write > 0) {
            // 打印日志，显示已写入的字节数
            ESP_LOGI(TAG, "[music] i2s music played, %d bytes are written.", bytes_write);
        } else {
            // 打印错误日志，提示音乐播放失败
            ESP_LOGE(TAG, "[music] i2s music play failed.");
            // 终止程序
            abort();
        }
        // 重置数据指针到音乐起始位置，实现循环播放
        data_ptr = (uint8_t *)music_pcm_start;
        // 延迟1秒再继续播放
        vTaskDelay(1000 / portTICK_PERIOD_MS);
    }
    // 删除当前任务
    vTaskDelete(NULL);
}
```

功能说明 ：FreeRTOS任务，负责循环播放PCM音频数据

执行流程 ：

1. 预加载数据 ：

- 禁用I2S发送通道

- 调用 i2s_channel_preload_data() 预加载音频数据到DMA缓冲区

- 移动数据指针，跳过已加载的数据

1. 使能通道 ：启用I2S发送通道，开始播放

1. 循环播放 ：

- 调用 i2s_channel_write() 写入音频数据

- 使用 portMAX_DELAY 无限等待，确保数据完全写入

- 检查写入状态，失败则终止程序

- 播放完成后重置数据指针到起始位置

- 延迟1秒后继续下一轮播放

- music_pcm_start ：PCM数据起始地址（从二进制文件嵌入）

- music_pcm_end ：PCM数据结束地址

**关键技术点总结**

1. 预加载机制

- 目的 ：避免播放开始的静音或爆音

- 实现 ：在使能通道前将数据写入DMA缓冲区

- 效果 ：通道使能后立即开始播放
- DMA双缓冲

- 机制 ：两个缓冲区交替使用

- 优势 ：一个播放时，另一个填充数据

- 结果 ：实现连续、无卡顿的音频播放

最后面的 EMBED_FILES 可以把文件加入到工程编译，canon.pcm 是音乐文件的名称，如果你的音乐文件名称是 xxx.pcm，就把这里的 canon 替换成 xxx。

在 main.c 的开始处，找到如下定义：



```
extern const uint8_t music_pcm_start[] asm("_binary_canon_pcm_start"); 
extern const uint8_t music_pcm_start[] asm("_binary_canon_pcm_end");
```

把 asm 里面的 canon 替换成你的 xxx 名称，例如 asm("_binary_xxx_pcm_start")。然后就可以在程序中使用 music_pcm_start 和 music_pcm_start 了。

 

**💡关于EMBED_FILES**

EMBED_FILES 会让构建系统把二进制文件直接链接进固件，链接器（GNU ld）会用 --format=binary 生成三个符号：



```
_binary_canon_pcm_start   → 数据起始地址
_binary_canon_pcm_end     → 数据结束地址
_binary_canon_pcm_size    → 数据大小
```

命名规则是：_binary_ + 文件名（canon.pcm 中的 . 被替换为 _）+ _start / _end / _size。

所以文件名是 canon.pcm，名字自然就是 _binary_canon_pcm_start / _binary_canon_pcm_end。

2. 为什么用 asm("...")

C 语言里以 _ 开头的标识符（_binary_...）是保留标识符，不能直接作为 C 变量名使用。而且如果直接写：



```C
extern const uint8_t music_pcm_start[];
```

编译器会去找名字叫 music_pcm_start 的链接器符号，但实际符号叫 _binary_canon_pcm_start，就对不上了。

asm("_binary_canon_pcm_start") 是 GNU C 扩展语法，作用是：告诉编译器"C 变量 music_pcm_start 对应汇编/链接层的符号 _binary_canon_pcm_start"。这样就把两者绑定起来，这个符号是由链接器生成的，C 源码里没有任何 .c 文件定义它。

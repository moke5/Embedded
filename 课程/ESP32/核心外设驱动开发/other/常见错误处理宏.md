# 常见错误处理宏

[toc]

**文件路径：components/esp_common/include/esp_err.h**

**1. ESP_ERROR_CHECK**

```C
#define ESP_ERROR_CHECK(x) do {                                         \
        esp_err_t __err_rc = (x);                                      \
        if (__err_rc != ESP_OK) {                                      \
            _esp_error_check_failed(__err_rc, __FILE__, __LINE__,      \
                                    __ASSERT_FUNC, #x);                \
        }                                                              \
    } while(0)
 
```

**行为**

1. 执行表达式x，得到esp_err_t返回值；

1. 如果返回值不等于ESP_OK，调用内部函数 _esp_error_check_failed()；

1. _esp_error_check_failed会打印错误码、文件名、行号、函数名，**直接调用abort()，程序崩溃重启**；

1. 只校验，**不会return，不会退出当前函数**。

适用场景：初始化等必须成功的操作，失败直接宕机。

**2. ESP_RETURN_ON_ERROR**

```C
#define ESP_RETURN_ON_ERROR(x) do {                 \
        esp_err_t __err_rc = (x);                  \
        if (__err_rc != ESP_OK) {                  \
            return __err_rc;                       \
        }                                          \
    } while(0)
 
```

**行为**

1. 执行表达式x，拿到错误码；

1. 如果非ESP_OK，**直接return该错误码，退出当前函数**；

1. 不会打印日志，不会崩溃，函数向上返回错误给上层调用者。

适用场景：函数内部出错，向上传递错误码，函数返回类型必须是esp_err_t。

| **宏**                 | **失败行为** | **返回**   | **崩溃**    | **日志打印**  |
| ---------------------- | ------------ | ---------- | ----------- | ------------- |
| ESP_ERROR_CHECK(x)     | 断言失败     | 不return   | ✅ abort重启 | ✅打印错误信息 |
| ESP_RETURN_ON_ERROR(x) | 函数返回     | return err | ❌不崩溃     | ❌无日志       |

 

开发商业项目建议：业务函数优先用**带log的ESP_RETURN_ON_ERROR**，初始化阶段硬件致命错误使用ESP_ERROR_CHECK。

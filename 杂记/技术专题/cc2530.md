### CC2530 GPIO

####  1.CC2530 I/O操作原理

CC2530 具有两个8位的输入输出端口P0、P1和一个5位的输入输出端口P2，共计21个数字I/O引脚，每个IO引脚均的配置成通用的IO端口、也可以配置成与定时器、ADC和USART串口等片内外设相关的具体特设功能的输入输出端口，端口的具体功能可通过软件配置相关寄存器来完成。

CC2530每组GPIO端口配置了4个8位寄存器，分别为功能选择寄存器PxSEL、方向控制寄存器PxDIR、输入模式控制寄存器PxINP和端口数据寄存器。每个IO引脚的具体功能由这些寄存器的设置完成。

<img src="./img/image-20260526202821310.png" width="70%">

### （一）各控制寄存器功能说明

1.端口功能选择寄存器(PxSEL)

PxSEL 为功能寄存器，是一个8位的寄存器，控制Px_0~Px_7对应端口的功能定义。为0时，表示对应端口为通用I/O端口; 为1时，表示对应端口为片内外部设备I/O端口。

P0SEL与P0口的控制映射关系如图5_x所示。

![img](https://p.ananas.chaoxing.com/star3/origin/7663957cf0c97e1b8e0df1e84fbd1a38.png)



图5_x P0SEL与P0口的控制映射关系

 

表2.5.1 P0口功能选择寄存器(P0SEL)  

| 位   | 名称        | 描述                                                         |
| ---- | ----------- | ------------------------------------------------------------ |
| 7:0  | SELP0_[7:0] | P0.7~P0.0功能选择控制位。0：通用IO；1：片内外设IO 。默认值为0 |

| 位   | 名称        | 描述                                              |
| ---- | ----------- | ------------------------------------------------- |
| 7:0  | SELP1_[7:0] | P1.7~P1.0功能选择控制位。0：通用IO；1：片内外设IO |

 

表2.5.x P2口功能选择寄存器(P2SEL)           

| 位   | 名称  | 描述                                         |
| ---- | ----- | -------------------------------------------- |
| 4    | SELP4 | P2.4功能选择控制位。0：通用IO；1：片内外设IO |
| 3    | SELP3 | P2.3功能选择控制位。0：通用IO；1：片内外设IO |
| 2    | SELP2 | P2.2功能选择控制位。0：通用IO；1：片内外设IO |
| 1    | SELP1 | P2.1功能选择控制位。0：通用IO；1：片内外设IO |
| 0    | SELP0 | P2.0功能选择控制位。0：通用IO；1：片内外设IO |

 

通用I/O端口是指可以对外输出逻辑值0（低电平）或1（高电平），也可读取从I/O引脚输入的逻辑值（低电平为0，高电平为1）。

CC2530内部除了含有8051CPU核心外，还具有其他功能模块，如ADC、定时器和串行通信模块，我们也称这些功能模块为外设。可通过编程将I/O口与这些外设建立起连接关系，以便这些外设与CC2530芯片外界电路进行信息交换。

 

2.方向控制寄存器（PxDIR）

PxDIR方向控制寄存器用于定义对应端口（Px_0~Px_7）的数据流动方向，即定义端口作为输入端口还是输出端口。设置为0时，表示对应端口为输入端口;；设置为1时，表示对应端口为输出端口。

在输出模式下，除了P1.0和P1.1外，每个IO口均采用推挽式输出，可提供输出（吸收）4Ma的电流。

输入模式下，需要进一步通过PxINP寄存器定义其输入模式。

| 7:0  | DIRP0_[7:0] | P0.7~P0.0方向控制位。0：输入；1：输出 |

 

表2.5.x P1口方向控制寄存器(P1DIR)      

| 位   | 名称        | 描述                                  |
| ---- | ----------- | ------------------------------------- |
| 7:0  | DIRP1_[7:0] | P1.7~P1.0方向控制位。0：输入；1：输出 |

3.输入模式选择寄存器（PxINP）

CC2530端口有3种输入模式（上拉、下拉或三态），因此，如果将端口设置输入，需要进一步定义端口的输入模式。它由PxINP寄存器来完成。

表2.5.x P0口输入模式选择寄存器(P0INP)

​      

| 位   | 名称        | 描述                                                   |
| ---- | ----------- | ------------------------------------------------------ |
| 7:0  | INPP0_[7:0] | P0.7~P0.0输入模式选择位。0：上拉/下拉输入；1：三态输入 |

 

表2.5.x P1口输入模式选择寄存器(P1INP)   

| 位   | 名称        | 描述                                                   |
| ---- | ----------- | ------------------------------------------------------ |
| 7:0  | INPP1_[7:0] | P1.7~P1.0输入模式选择位。0：上拉/下拉输入；1：三态输入 |

 

表2.5.x P2口输入模式选择寄存器(P2INP)               

| 位   | 名称       | 描述                                                   |
| ---- | ---------- | ------------------------------------------------------ |
| 7    | INPP2_[7]  | P2口上拉/下拉输入模式选择:。：0：上拉输入；1：下拉输入 |
| 6    | INPP2_[6]  | P1口上拉/下拉输入模式选择:。：0：上拉输入；1：下拉输入 |
| 5    | INPP2_[5]  | P0口上拉/下拉输入模式选择:。：0：上拉输入；1：下拉输入 |
| 4:0  | INPP2_[4:0 | P2.4~P2.0入模式选择位。0：上拉/下拉输入；1：三态输     |

 

由此，当将一个端口定义为输入端口时，除了设置PxDIR寄存器之外，还需要设置PxINP寄存器，其中，P2INP的高3位用于进一步定义各端口的上拉或下拉模式。

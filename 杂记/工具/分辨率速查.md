# 分辨率速查

[toc]

## 一、图像 / 屏幕分辨率（尺寸）

> W=Width 宽度；H=Height 高度，单位 px（pixel 像素）

| 缩写    | 全称       | 含义   | 示例         |
| :------ | :--------- | :----- | :----------- |
| **px**  | pixel      | 像素   | 1920×1080 px |
| **res** | resolution | 分辨率 | Res:1280×720 |
| **W**   | Width      | 宽     | W=1920       |
| **H**   | Height     | 高     | H=1080       |

### 常见分辨率简称（行业叫法）

| 简称         | 完整分辨率 |
| :----------- | :--------- |
| QVGA         | 320×240    |
| VGA          | 640×480    |
| WVGA         | 800×480    |
| SVGA         | 800×600    |
| XGA          | 1024×768   |
| HD / 720P    | 1280×720   |
| FHD / 1080P  | 1920×1080  |
| QHD / **2K** | 2560×1440  |
| UHD / **4K** | 3840×2160  |
| **8K**       | 7680×4320  |

> P：Progressive 逐行扫描；i：Interlaced 隔行，如 1080i。

## 二、空间分辨率（传感器、相机、打印，单位密度）

| 缩写    | 全称            | 说明                     |
| :------ | :-------------- | :----------------------- |
| **DPI** | Dots Per Inch   | 每英寸点数，打印机、鼠标 |
| **PPI** | Pixels Per Inch | 每英寸像素，屏幕、显示器 |
| **LPI** | Lines Per Inch  | 每英寸线数，印刷网纹     |

> 注意区分：
>
> - PPI：**屏幕硬件像素密度**
> - DPI：打印 / 输出墨点，鼠标 DPI

## 三、嵌入式 / 图像算法领域缩写

| 缩写 | 全称               | 释义                     |
| :--- | :----------------- | :----------------------- |
| ROI  | Region of Interest | 感兴趣区域，图像裁剪区域 |
| FOV  | Field Of View      | 视场角，镜头可视范围     |

## 四、存储 / 码流相关（视频）

| 缩写 | 全称              | 含义                                       |
| :--- | :---------------- | :----------------------------------------- |
| FPS  | Frames Per Second | 帧率，每秒帧数，不是分辨率，但经常一起出现 |

### 快速区分易混

1. `px`：一张图总像素尺寸；
2. `PPI/DPI`：单位英寸内点数（密度）；
3. `720P/1080P/4K`：市场俗称分辨率。

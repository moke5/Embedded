# 整体模块拆分（核心架构）

你的 xsh 输入部分应该变成：

```
xsh/
 ├── input.c        → 输入读取层（read）
 ├── parser.c       → 字节解析层（ESC序列）
 ├── history.c      → 历史管理
 ├── line.c         → 当前编辑行（核心buffer）
 ├── render.c       → 屏幕刷新
 ├── xsh.c          → 主循环
```

------

# 每一层做什么（非常重要）

------

## 1️⃣ input.c（只负责一件事）

```
从TTY读原始字节
```

特点：

```
不解释任何东西
不判断方向键
不处理逻辑
```

输出：

```
byte stream
```

------

## 2️⃣ parser.c（事件翻译器）

作用：

```
把字节流 → 输入事件
```

例如：

```
0x1b 0x5b 0x41 → KEY_UP
```

输出：

```
event
```

------

## 3️⃣ history.c（状态存储）

负责：

```
保存所有历史命令
```

功能：

```
add(command)
get_previous()
get_next()
```

------

## 4️⃣ line.c（当前编辑核心）

这是最重要的：

```
当前输入行 buffer
```

功能：

```
插入字符
删除字符
替换整行（上键）
```

------

## 5️⃣ render.c（刷新屏幕）

作用：

```
把 line buffer 显示到终端
```

关键：

```
清屏 + 重画
```

------

# 数据流（你必须记住）

这是整个系统核心：

```
read()
  ↓
input.c
  ↓
parser.c
  ↓
event
  ↓
line.c + history.c
  ↓
render.c
```



```
STATE_NORMAL
STATE_ESC
STATE_ESC_BRACKET
```



```
输入
↓
解析
↓
状态
↓
处理
↓
输出
```



### 数据流

```
键盘
 ↓
TTY  （raw mode）
 ↓
input （read）
 ↓
parser （解析数据，返回事件）
 ↓
产生 event
 ↓
history （管理历史命令）
├── commands[]
├── current_index
└── saved_line
 ↓
line （管理当前命令）
├── buffer
├── cursor_pos
└── length
 ↓
render （显示到终端）
 ↓
屏幕
```

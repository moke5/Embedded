TTY：系统行为问题（不是API问题）



使用 `if (fgets(command, sizeof(command), stdin) == NULL) break;` 读取输入：

- 上下左右键显示 `^[[A ^[[B ^[[C ^[[D`

```
键盘
↓
终端驱动（TTY）
↓
内核缓冲区（按行/按模式处理）
↓
fgets / read
↓
你的程序
```



fgets在“谁控制输入？”

```
fgets ≠ 直接读键盘
```

它读的是：

```
stdin → 终端（TTY）提供的数据流
因为它依赖TTY的按行缓冲机制
方向键是控制序列而不是输入字符
```



为什么方向键是 ^[[A

按方向键时：

```
键盘 → 终端 → 产生“转义序列”
```

例如：

```
↑
= ESC [ A
= \x1b [ A
= ^[[A
```

所以：

```
fgets看到的不是“一个键”
而是“多个字符组成的序列”
```



为什么fgets“无法处理方向键”

因为 fgets 做的事情只有：

```
从 stdin 读“字节流”
直到：
- \n
- buffer满
```

它完全不理解：

```
这是按键
这是控制序列
```

它只看到：

```
0x1b '[' 'A'
```

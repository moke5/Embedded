# 校验与提交规范

> 本文件是校验、分支和提交规则的唯一来源；`AGENTS.md` 只保留命令与入口。

## 1. 校验

| 命令 | 范围 | 用途 |
| --- | --- | --- |
| `python script/notes_lint.py` | 全量 | 日常检查 |
| `python script/notes_lint.py --strict` | 全量，告警按错误 | 提交前 |
| `python script/notes_lint.py --changed` | 暂存区 | pre-commit |

校验内容：frontmatter 必填字段与取值、文件名、断链、空标题、疑似私钥、token、手机号、身份证号、公网 IP。新笔记缺 frontmatter 记为错误，既有笔记仅告警。

脚本依赖 Python 3 与 PyYAML：

```bash
python -m pip install pyyaml
```

pre-commit 可选安装：

```bash
cp script/hooks/pre-commit .git/hooks/pre-commit
chmod +x .git/hooks/pre-commit
```

Windows PowerShell：

```powershell
Copy-Item script/hooks/pre-commit .git/hooks/pre-commit
```

## 2. 分支模型

- `main` 为主分支，只接收完成并通过校验的修复与新增。
- 每项工作单独建分支；完成后合入 `main`，合入后删除工作分支。
- 分支前缀：修复 `fix/<主题>`、新增 `feat/<主题>`、文档 `docs/<主题>`、基线整理 `chore/<主题>`；同一分支只放一类改动。
- 每项工作对应一个提交，提交说明与分支主题一致。

## 3. 执行步骤

1. 从最新 `main` 建分支：

```bash
git switch main
git switch -c docs/<主题>
```

2. 修改后校验：

```bash
python script/notes_lint.py --strict
git diff --check
```

3. 暂存并提交：

```bash
git add -A
git commit
```

4. 合入主分支：

```bash
git switch main
git merge --ff-only docs/<主题>
git branch -d docs/<主题>
```

5. 推送前征得用户同意；双远程依次推送：

```bash
git push gitee main
git push origin main
```

## 4. 提交信息

- commit message 用中文，说明修改动机、影响范围和原因。
- 模板见 `.gitmessage`；本地启用：

```bash
git config commit.template .gitmessage
```

- 提交前检查 `git status` 与 `git diff --check`。
- 未经用户要求，不主动提交或推送。

## 5. 回滚

- 未提交的改动用 `git restore` 或 `git checkout -- <路径>` 恢复。
- 已提交未推送的改动用 `git revert <提交>` 生成反向提交；不改写公共历史。
- 推送后发现问题，优先追加修复提交；强制推送需用户明确同意。

## 6. 完成检查

1. `python script/notes_lint.py --strict` 返回 0。
2. `git diff --check` 无输出。
3. 改动范围与分支主题一致，无无关文件。
4. 提交信息包含动机、范围与原因。
5. 推送前已获得用户同意。

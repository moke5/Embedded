## 命名规范

- **目录/文件**：中文为主，技术专名保留英文（LVGL、STM32、gcc）
- **课程笔记**：`主题名.md`，不加数字序号前缀——学习顺序记在主题 MOC 索引里，文件名不承担排序功能
- **图片**：统一放同级 `img/` 目录（Typora 的 `.assets` 目录与笔记同名配对）——**不入库**（已 gitignore），远程仓库只备文本
- **索引**：`课程/`、`项目/`、`杂记/`、`AI/`、`本机/` 各有一个顶层 `MOC.md`，统一索引其全部子目录；子目录默认复用上级 MOC，需要独立入口时可另建。头部记录来源期号，正文按学习顺序列链接
- **禁止**：新增英文小写碎片命名（如 `url.md`、`code.md`）；用期号/日期做目录层级（历史已扁平化）

## 分支与提交

- `main` 为主分支，只接收完成并通过校验的内容。
- 修复用 `fix/<主题>`，新增用 `feat/<主题>`，文档用 `docs/<主题>`；一项工作一个提交，完成后合入 `main`。
- 提交信息用中文，模板见 `.gitmessage`；提交前运行 `python script/notes_lint.py --changed`。
- 详细规则见 [AGENTS.md](./AGENTS.md) 第 9 节。

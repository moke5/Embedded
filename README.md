## 命名规范

- **目录/文件**：中文为主，技术专名保留英文（LVGL、STM32、gcc）
- **课程笔记**：`主题名.md`，不加数字序号前缀——学习顺序记在主题 MOC 索引里，文件名不承担排序功能
- **图片**：统一放同级 `img/` 目录（Typora 的 `.assets` 目录与笔记同名配对）——**不入库**（已 gitignore），远程仓库只备文本
- **索引**：每个主题目录一个 `MOC.md`，头部记录来源期号，正文按学习顺序列链接
- **禁止**：新增英文小写碎片命名（如 `url.md`、`code.md`）；用期号/日期做目录层级（历史已扁平化）

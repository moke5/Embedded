### 区别



- 方式一

```
// 第一种方式是阻塞式的，会让程序白白等待2秒才执行函数
delay_ms(2000);
f();
```



- 方式二

```
// 第二种方式是非阻塞的，任务之间不会互相干扰
if(t >= 1000)
{
	f();
	t = 0;
}
```

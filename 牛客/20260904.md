### Question

#### PWM

1.在使用单片机定时器产生PWM信号时，若保持定时器的周期（Period）寄存器值不变，仅增加比较/捕获（Compare/Capture）寄存器的值，输出的PWM信号会发生什么变化？

A 频率增加，占空比不变。

B 频率不变，占空比增加。

C 频率降低，占空比增加。

D 频率和占空比都保持不变。



##### Analysis

```
官方解析：
在PWM信号生成中，定时器的周期寄存器（Period）决定信号频率（f = 1/T，T为周期），而比较/捕获寄存器（Compare/Capture）决定占空比（Duty Cycle = (比较值 / 周期值) * 100%）。当周期寄存器值不变时，频率不变；仅增加比较/捕获寄存器的值，会导致高电平时间增加，从而占空比增加。
```

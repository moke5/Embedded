### 嵌入式Linux到底有哪些岗位

#### 第一类

嵌入式Linux应用开发

例如：

```
摄像头
机器人
工业控制
智能家居
网关
```

工作内容：

```
线程
socket
串口
数据库
协议
业务逻辑
```

------

#### 第二类

BSP工程师

工作内容：

```
移植Linux
U-Boot
设备树
驱动适配
```

------

#### 第三类

驱动工程师

工作内容：

```
I2C
SPI
UART
GPIO
DMA
中断
字符设备
```

------

#### 第四类

系统软件工程师

工作内容：

```
Linux系统
性能优化
网络
中间件
```

------

#### 六、AI对哪些岗位影响最大

说实话：

最危险的是：

```
简单业务开发
```

例如：

```
增删改查
后台管理
简单网页
```

------

而：

```
驱动
嵌入式
系统软件
```

影响相对小很多。

因为这里经常出现：

```
硬件
时序
性能
调试
```

AI无法直接替代。
